Input generation now stops with an error where regridding leaves NaN at an ocean point, instead of silently writing 0 there (roms-tools 5.4.0).
- ``bypass_validation: true`` on a Forge blueprint's ``initial_conditions`` or ``boundary`` writes 0 there as before.
- A ``nest_ic`` child grid that reaches the edge of its parent grid now fails, since the parent has no velocities there; keep the child inside the parent.
