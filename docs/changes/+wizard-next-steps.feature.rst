The wizard's blueprint page has a new **Next steps** section that saves a workplan to forge the saved blueprint's inputs and then run UCLA-ROMS, ready for ``cstar workplan submit``.
- **Open in the Workplan builder** adds the same two steps to the Workplan page, to add compute settings or more steps before submitting.
- **Run Forge here** (formerly **Run**) and **Save specs to the catalog** moved into Next steps from Review and export, which now ends at saving the blueprint.
- Save workplan and Run Forge here are available once the blueprint is saved, and again after each change is saved.
