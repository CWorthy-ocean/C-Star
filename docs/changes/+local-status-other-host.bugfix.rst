A step running as a local process, such as a ``--pre-run``, is no longer reported and recorded as failed when ``cstar run status`` is asked on another machine than the one running it (another login node, for example); that machine shows the step's last recorded status.
- Re-running the workplan from another machine while the step is still in progress is refused, naming the machine that runs it; before, the step could start again beside itself. Wait for it to finish, run the command on that machine, or pass ``--clobber`` to start over after stopping the other process yourself.
