The default ModelSpec, the wizard default, the bundled domains and the integration pin move to ``roms-marbl-0.16-default`` (ucla-roms 0.16.0), which writes different output from an unchanged setup; ``roms-marbl-0.15-default``, ``roms-marbl-0.14-default`` and ``roms-marbl-0.13-default`` stay for reproducing earlier answers.
- 3-D results change: the predictor step splits the vertical velocity differently (ucla-roms #468), and lateral viscosity, including the sponge's, now acts on the depth-averaged flow, which changes ``ubar``, ``vbar`` and ``zeta`` most in the sponge layer (ucla-roms #473).
- Each record of the ``_avg`` and ``_bgc_avg`` files averages the model states one step later than before, and these files and ``_bgc_dia_avg`` gain ``avg_begin_time`` and ``avg_end_time``; pair ``_avg`` and ``_bgc_avg`` records by ``avg_end_time`` (ucla-roms #472).
- ``w`` in history, averages and boundary output includes the water added by point sources, such as CDR releases with ``cdr_volume`` (ucla-roms #470).
- Parameterized CDR releases spread over several cells (``cdr_hsc`` > 0) can change at the rounding level: their weights no longer depend on the tiling (ucla-roms #470).
- Builds without ParallelIO write their per-rank output as uncompressed CDF-5 instead of netCDF-4, so those files are larger; joined files are still compressed netCDF-4 (ucla-roms #470).
