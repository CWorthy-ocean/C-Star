C-Star ships skills for coding agents (Claude Code, Codex, Gemini CLI, GitHub Copilot and others), starting with ``cstar-system``, which writes and tests a system file for a cluster C-Star does not know; see "With a coding agent" in "Describe your cluster".
- ``cstar skill install`` links the shipped skills into ``~/.agents/skills`` and, when ``~/.claude`` exists, ``~/.claude/skills``; ``cstar skill list`` shows where each is installed.
- ``cstar init`` offers the install when it finds a coding agent's folder in your home directory.
