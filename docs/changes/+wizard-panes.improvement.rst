The wizard shows more without opening anything: pane headers list the current choices, and each output stream shows its period in days or hours and how many files the run writes.
- Each forcing item keeps its regridding and roms-tools options under its own disclosure, which says how many differ from their defaults.
- The history and average variable lists fold into one line each, with a count of the variables selected and a note when that stream is off.
- Derived numbers such as the sponge viscosity are rounded for display, and the MARBL tracer and diagnostic lists wrap so the whole list shows.
