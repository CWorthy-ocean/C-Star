With flexible start time (``initial_conditions.allow_flex_time``), the initial conditions are now stamped at ``start_date``, so ROMS starts there; before, ROMS started at the source record roms-tools took (up to 24 hours later) while the blueprint, the forcing and the CDR releases kept the requested dates. The record's own time is kept in the file's ``ini_time_source_record`` attribute, and Forge warns when it differs from ``start_date``.
