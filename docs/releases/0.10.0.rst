0.10.0
----------


Breaking Changes
~~~~~~~~~~~~~~~~


- Specifying external apps via ``CSTAR_APP_MODULES`` is no longer valid; use entry-point approach instead (`#622 <https://github.com/CWorthy-ocean/C-Star/pull/622>`_)

New features
~~~~~~~~~~~~


- External apps can now be registered via entry-points (`#622 <https://github.com/CWorthy-ocean/C-Star/pull/622>`_)

Improvements
~~~~~~~~~~~~


- PIO-enabled builds now output extracted child boundaries in the ``output`` directory instead of the ``work`` directory (`#623 <https://github.com/CWorthy-ocean/C-Star/pull/623>`_)
